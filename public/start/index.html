Öffnen Sie den Vertragsnavigator mit Ihren bestehenden Zugangsdaten. Sie können ihn anschließend wie eine normale Anwendung auf Ihrem PC installieren – ohne zusätzliche Software.

Als App auf dem Desktop installieren

Einmal einrichten, danach bequem über das App-Symbol im Startmenü oder auf dem Desktop öffnen. Die Installation erfolgt auf der eigentlichen Vertragsnavigator-Seite, nicht auf dieser Anleitung.

Microsoft Edge · Windows

1Oben auf „Vertragsnavigator öffnen“ klicken.
2In Edge rechts oben auf ⋯ klicken und Apps → Diese Website als App installieren wählen.
3Mit „Installieren“ bestätigen. Falls angeboten, Desktopverknüpfung erstellen aktivieren.

Google Chrome · Windows

1Oben auf „Vertragsnavigator öffnen“ klicken.
2In Chrome rechts oben auf ⋮ klicken und „Seite als App installieren“ auswählen (ggf. unter „Speichern und teilen“).
3Installation bestätigen. Der Vertragsnavigator kann danach wie eine Desktop-Anwendung gestartet werden.
Falls „Als App installieren“ nicht angezeigt wird: Öffnen Sie den Vertragsnavigator und erstellen Sie stattdessen eine normale Desktopverknüpfung über das Browsermenü oder ziehen Sie das Symbol links neben der Webadresse auf den Desktop. Menübezeichnungen können je nach Browserversion abweichen.
